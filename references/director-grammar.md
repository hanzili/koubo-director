# 通用导演语法与节奏规范（Director Grammar）

这套语法来自对头部竖屏知识讲解视频的逐帧拆解以及真实成片返工教训，**跨行业 100% 通用**。

## 一、四条视觉铁律

1. **动在屏内，少换整屏（Within-Screen Accumulation）**
   - 观众觉得“太快太赶”，根因不是信息多，而是每 3–4 秒整屏清掉换新底，观众来不及看前文。
   - **做法**：同一组逻辑（`8–15s`）留在同一画布上，用组件内置时间戳让新行/新节点/新气泡逐个出现，旧信息留在旁边供回看；真正换话题才换整屏背景。
2. **切屏前必留 ≥0.5–0.6s 静止吸收窗口（Settle Dwell）**
   - 任何图卡的最后一个动画元素落地时间 `t_last`，必须满足 `t_block_end - t_last >= 0.6s`（短卡底线 `0.5s`），让观众视线真正读完再切走。
3. **贯穿主板回访 + 真东西交替**
   - 每集选 1 块核心主板（`ledger_board` / `chain_card` / `chapter_deck` / `split_bars`），全片回访 3–5 次，但**单次 ≤15s、累计 ≤25%**。
   - 两次主板之间必须穿插**真东西**（实拍、真网站 `screen_callout`、真单据 `quote_zoom`、实拍对比 `split_compare`）以及纯真人呼吸段，素材回放率 ≤5%。
4. **首尾与粗剪纪律**
   - **开场 1 秒内**出第一个视觉冲击点（`photo_hero` / `vs_duel` / `waffle_card` / `map_route`），15 秒内至少 1 个真东西；
   - **粗剪去伸手帧**：切掉每个 take 首尾伸手碰屏幕的动作；结尾挥手道别后 `0.15–0.25s` 立即切满版收尾卡，彻底杜绝伸手关镜画面；
   - **竖屏防畸变**：入库前检测分辨率，若竖屏会话混入横屏拉伸 WebM/MP4（`w > h` 且无旋转标签），用 `scale=1080:1920,setsar=1` 还原 1:1 人脸比例。

## 二、三档节奏预设（在 `channel.yaml` 选择 `rhythm_preset`）

| 指标 | `deep-explainer`（深度讲解，默认） | `fast-take`（快节奏干货/热点） | `documentary`（故事/人物纪录片） |
|---|---|---|---|
| `≥8s` 持续画布占比 | **≥ 45%** | ≥ 32% | **≥ 55%** |
| `<4s` 短切占比 | **≤ 25%** | ≤ 40% | **≤ 18%** |
| 整屏换底频率 | **≤ 7.5 次/分** | ≤ 10 次/分 | **≤ 5.5 次/分** |
| 纯真人呼吸感占比 | **18% – 25%** | 12% – 18% | **25% – 35%** |
| 切屏前静止吸收 | **≥ 0.6s** | ≥ 0.5s | **≥ 0.8s** |
| 推荐默认皮肤 | `obsidian` / `editorial` | `cyber` / `obsidian` | `editorial` / `vintage` |

## 三、音频与配乐动态语法

- **整体响度**：成片统一归一化至 **`-16.0 LUFS ± 0.5`**，人声清晰优先。
- **配乐不能拉成死直线**：在 `music_plan.json` 按段落内容明确拉开 `level` 偏移：
  - 讲细节/算账/原件阅读（稀）：`-5 .. -6 dB`
  - 正常推进（中）：`-1 .. 0 dB`
  - 开场钩子 / 强反转 / 结尾升华（满）：`+3 .. +4 dB`
  - 目标成片疏密动态差 **`≥ 15 dB`**，`percue` 与规划偏差 spread **`≤ 3 dB`**。
- **换段与音效**：换情绪用短上扬/重击带入，避免 2 秒尴尬真空；音效克制在 `3–6 个/分`，SMPTE 彩条转场 `bars` 全片最多 1–2 次。
